# DSH-m v2.11.0

## 中文

DSH-m v2.11.0 是「iOS 原生导航」版本：会话页的进入/返回整体迁移到系统导航栈（SwiftUI `NavigationStack`，底层 `UINavigationController`）——左缘滑动返回与推入/弹出转场全部是 Apple 官方动效，替换上一版自绘的边缘返回手势与子代理返回的整页冻结位图机制；同时按需求精简两处状态展示。

- 新增：
  - 无产品级新增；本版为导航层重构与体验精简（见「改进」）。
- 改进：
  - **iOS 原生导航**：删除自绘边缘返回（22pt 热区 + 位移阈值 + easeOut 收尾）与子代理返回位图快照；工作区列表作为导航栈根常驻，返回即时可交互（不再有 1-3s 列表重建冻结）；子代理详情返回直接显示活的父会话。
  - **滚动中也能边缘返回**：手势仲裁对齐系统原生行为——消息列表正在滚动/减速时，从屏幕左缘右滑可直接触发系统返回（此前会被列表滚动手势抢占，加载期尤其明显）。
  - **状态展示精简**：会话列表右上角状态指示只保留「圆点 + 在线」等状态文案（不再展示 IP/host）；会话详情页标题下的小行（连接状态点 + host · 运行中/空闲）整行移除。
- 修复：
  - 修复点通知在会话间跳转（深链替换）**被弹回旧会话**：同层替换时 `@StateObject` 沿用旧会话数据——恢复 `.id(sessionId)` 身份强制重建，并加入导航回声窗防护（动画中段 SwiftUI 回写旧 path 一律忽略）与瞬时直写（消除替换转场竞态）。
  - 修复**隐藏系统导航栏导致 iOS 禁用其自带边缘返回手势**：以约 70 行 UIKit 桥接（`SystemEdgePopBridge`，用户批准的互操作例外）重新启用 Apple 自己的识别器与转场，未自绘任何手势或动效。
  - 修复**子代理详情加载期边缘返回经常点不中**（真机手势事件日志取证：识别器被列表滚动抢占；补上 `shouldRecognizeSimultaneouslyWith` 仲裁规则后用户复现验证通过）。
- 已知限制：
  - 进入会话/深链换页为瞬时切换（与旧版一致），不带系统推入滑动动画；系统动画只用于返回（边缘滑动与标题返回按钮）。
  - 物理边缘滑动的验收无法全自动化（Xcode 26 合成手势驱动不了系统边缘识别器），由真机人工验收覆盖；自动化门禁覆盖返回/替换语义与手势仲裁规则。

### 验证（实跑）

## English

DSH-m v2.11.0 is the "native iOS navigation" release: session pages now live in the system navigation stack (SwiftUI `NavigationStack`, backed by `UINavigationController`) — the left-edge swipe-back and the push/pop transitions are Apple's own, replacing the previous custom edge gesture and the frozen-snapshot reveal for subagent back navigation; two status displays are slimmed down per requirement.

- Added:
  - No product-level additions; this release is the navigation rework plus status-display slimming (see Improved).
- Improved:
  - **Native iOS navigation**: the custom edge-swipe (22pt hot zone + distance thresholds + easeOut finish) and the subagent back bitmap snapshot are gone; the workspace list stays mounted as the stack root, so returning is instant and interactive (no more 1-3s list-rebuild freeze); backing out of a subagent detail shows the live parent session directly.
  - **Edge-swipe back works while scrolling**: gesture arbitration restored to the system-native rule — swiping from the left bezel triggers the system back even while the message list is still scrolling/decelerating (previously the list pan could swallow it, most visibly during loading).
  - **Slimmer status displays**: the workspace-list pill shows only the dot + phase label (no IP/host); the small line under the session-detail title (connection dot + host · running/idle) is removed entirely.
- Fixed:
  - Fixed a notification deep-link jump between sessions **snapping back to the old session**: on a same-level replace the `@StateObject` kept the previous session's data — `.id(sessionId)` restores per-session identity, with a navigation-echo guard (mid-transition path re-writes ignored) and instant writes (no replace-transition race).
  - Fixed **iOS gating its own edge-swipe recognizer when the system navigation bar is hidden**: a ~70-line UIKit bridge (`SystemEdgePopBridge`, a user-approved interop exception) re-enables Apple's own recognizer and transition — no custom gesture or animation is drawn.
  - Fixed **edge-swipe back frequently dead while a subagent detail is loading** (real-device gesture-event log evidence: the recognizer lost arbitration to the list pan; adding the `shouldRecognizeSimultaneouslyWith` rule fixed it, user-verified on device).
- Known limitations:
  - Entering a session and deep-link replacement are instant swaps (same as before), without the system push slide; the system animation is used for pops (edge swipe and the header back button).
  - Physical edge-swipe acceptance cannot be fully automated (Xcode 26 synthetic gestures cannot drive the system edge recognizer) and is covered by manual device acceptance; automated gates cover pop/replace semantics and the arbitration rule.

### Verification (executed)

- iOS unit tests: `DSHmTests` **921 tests / 0 failures** (simulator iPhone 17, Xcode 27.1; incl. +12 navigation path/echo regression cases).
- Real-device E2E (iPhone 16 Pro Max / iOS 27.0.1): SessionHistory 10 + NavigationPop 2 + NavigationReplace 1 = **13/13**; scroll insert-stability jitter gate PASS.
- Gesture issue closed the evidence way: `nav-events.log` (DEBUG-gated diagnostics channel) pinpointed the arbitration loss → fix → user-verified "back works during loading" on device.
- Plugin suites: apns-payload-shape 11/11, m2-reload-handoff 3/3, m2-transport 8/8.
