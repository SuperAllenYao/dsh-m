# v2.11.0

## 中文

- 改进：
  - 返回跟手了：从屏幕左缘右滑即可返回上一页，动画与 iPhone 自带应用完全一致；消息列表正在滚动时也能直接滑出。
  - 返回即刻可用：不再有返回后列表卡住 1–3 秒无法滚动的情况；从子代理会话返回时，父会话立刻完整呈现。
  - 界面更清爽：列表右上角只显示连接状态（如「在线」），不再展示 IP 地址；会话页标题下的小字行已移除，只留标题。
- 修复：
  - 修复点通知打开另一个会话时、偶尔被弹回原来会话的问题。
  - 修复子代理会话加载期间、从左缘滑动返回经常无反应的问题。
  - 修复左缘滑动返回被完全禁用的问题（现为系统原生手势与动画）。

## English

- Improvements:
  - Back finally feels native: swipe from the left edge to return, with the exact animation iOS uses everywhere — and it works even while the message list is still scrolling.
  - Returning is instant: no more 1–3 second frozen list after going back, and backing out of a subagent session shows the parent session immediately, fully intact.
  - A cleaner look: the list's top-right shows only the connection state (e.g. "在线") without the IP address, and the small line under the session title is gone.
- Fixes:
  - Fixed tapping a notification to open another session occasionally snapping back to the previous one.
  - Fixed the left-edge swipe frequently not responding while a subagent session was still loading.
  - Fixed the left-edge swipe being disabled entirely (it's now the genuine system gesture and animation).
