# v2.11.0 — 2026-10-25

## 新增 / New

- 无产品级新增；本版为导航层重构与体验精简（新增项见「改进」）。/ No product-level additions; this release is the navigation rework and status-display slimming (see Improvements).

## 改进 / Improvements

- **iOS 原生导航**：会话页进入/返回迁移到系统导航栈（SwiftUI `NavigationStack`，底层 `UINavigationController`）——左缘滑动返回与推入/弹出转场全部是 Apple 官方动效；删除上一版自绘的边缘返回手势（22pt 热区 + 位移阈值 + easeOut 收尾）与子代理返回用的整页冻结位图机制。工作区列表作为导航栈根常驻，返回即时可交互（不再有 1-3s 的列表重建冻结）。/ Native iOS navigation: session pages now live in the system navigation stack (`NavigationStack` backed by `UINavigationController`) — the left-edge swipe-back and the push/pop transitions are Apple's own; the previous custom edge gesture (22pt hot zone + distance thresholds + easeOut finish) and the frozen-snapshot reveal for subagent back navigation are gone. The workspace list stays mounted as the stack root, so returning to it is instant and interactive.
- **滚动中也能边缘返回**：手势仲裁对齐系统原生行为——消息列表正在滚动/减速时，从屏幕左缘右滑可直接触发系统返回（此前会被列表滚动手势抢占）。/ Edge-swipe back now works while the message list is still scrolling/decelerating (gesture arbitration restored to the system-native rule; previously the list pan could swallow the bezel swipe).
- **状态展示精简**：会话列表右上角状态指示只保留「圆点 + 在线」等状态文案（不再展示 IP/host）；会话详情页标题下的小行（连接状态点 + host · 运行中/空闲）整行移除，标题更聚焦。/ Slimmer status display: the workspace-list pill shows only the dot + phase label (no IP/host); the small line under the session-detail title (connection dot + host · running/idle) is removed entirely.
- E2E 资产：新增导航门禁用例（返回/子代理返回/运行时替换）与手势事件诊断通道（`DSHM_NAVDBG` 落盘 `Documents/nav-events.log`，DEBUG 门控）。/ E2E: new navigation gate cases (pop / subagent pop / runtime replace) plus a gesture-event diagnostics channel (`DSHM_NAVDBG` writes `Documents/nav-events.log`, DEBUG-gated).

## 修复 / Fixes

- 点通知在会话间跳转（深链替换）被弹回旧会话：同层替换时 `@StateObject` 沿用旧会话数据——恢复 `.id(sessionId)` 身份强制重建；并加入导航回声窗防护（动画中段 SwiftUI 回写旧 path 一律忽略）与瞬时直写（消除替换转场竞态）。/ Fixed a notification deep-link jump between sessions snapping back to the old one: on a same-level replace the `@StateObject` kept the previous session's data — `.id(sessionId)` restores per-session identity, with a navigation-echo guard (mid-transition path re-writes are ignored) and instant writes (no replace-transition race).
- 隐藏系统导航栏导致 iOS 禁用其自带边缘返回手势：以 ~70 行 UIKit 桥接（`SystemEdgePopBridge`，用户批准的互操作例外）重新启用 Apple 自己的识别器与转场，未自绘任何手势或动效。/ With the system navigation bar hidden, iOS gates its own edge-swipe recognizer: a ~70-line UIKit bridge (user-approved interop exception) re-enables Apple's own recognizer and transition — no custom gesture or animation is drawn.

## 已知限制 / Known limitations

- 进入会话/深链换页为瞬时切换（与旧版一致），不带系统推入滑动动画；系统动画只用于返回（边缘滑动与标题返回按钮）。/ Entering a session and deep-link replacement are instant swaps (same as before); the system animation is used for pops (edge swipe and the header back button).
- 物理边缘滑动的验收无法全自动化（Xcode 26 合成手势驱动不了系统边缘识别器），由真机人工验收覆盖；自动化门禁覆盖返回/替换语义与手势仲裁规则。/ Physical edge-swipe acceptance cannot be fully automated (Xcode 26 synthetic gestures cannot drive the system edge recognizer) and is covered by manual device acceptance; automated gates cover pop/replace semantics and the arbitration rule.
