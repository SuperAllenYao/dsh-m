# v0.2.3

## 中文

- 新增：
  - 会话页改为与桌面端一致的平铺消息流：不再有轮次卡片，推理与工具调用按过程组折叠，文件变更汇总在流尾。
  - 连接自动适应：Wi-Fi、蜂窝、热点或电脑更换地址后，自动切到当前最快的路径。
- 改进：
  - 长会话滚动更稳，下拉加载的新消息立即可见。
  - 连接更快：冷启动约 1.6 秒、切换网络后约 0.4 秒自动重连（此前可能要等几十秒）。
- 修复：
  - 修复网络环境变化后长时间连不上、或反复重试极慢的问题。
  - 修复旧连接未释放时新连接被卡住等待超时的问题。

## English

- New:
  - The session page is now a flat message stream matching the desktop: no turn cards, reasoning and tool calls folded into process groups, file changes summarized at the end.
  - The connection adapts on its own: Wi-Fi, cellular, hotspot or a changed Mac address — the app switches to the currently fastest path.
- Improvements:
  - Long sessions scroll more smoothly, and newly loaded messages appear right away.
  - Faster connections: about 1.6 s cold start and about 0.4 s reconnect after switching networks (previously up to tens of seconds).
- Fixes:
  - Fixed long failures or endless slow retries after the network changed.
  - Fixed new connections getting stuck waiting for a timeout while an old one hadn't been released.
