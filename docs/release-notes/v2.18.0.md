# v2.18.0

## 中文

- 新增：
  - 会话历史改用更紧凑的传输格式：跨网（蜂窝 / 中继）打开大会话，历史加载从约半分钟降到约 1.3 秒，打开后约 0.4 秒内就能看到内容。
- 改进：
  - 大会话详情打开更快：进入即取、边取边显示，不用等整页加载完才看到内容。
  - 下拉加载更早、更顺：下一页提前取好，滚到顶部时新内容通常已经就位。
  - 连接建立更利落：连接冲突时的等待从 1.5 秒缩短到约 0.8 秒，弱网下自动放宽，减少无谓重试。
  - 下行内容压缩：蜂窝网络下同样的内容传得更快、更省流量。
- 修复：
  - 修复大会话叠加实时输出时，会话详情卡死、滚动与手势失灵的问题。

## English

- New:
  - Session history now travels in a more compact format: opening a long session across networks loads its history in about 1.3s instead of about half a minute, and shows content within about 0.4s.
- Improvements:
  - Large session details open faster: content is fetched as you enter and shown progressively instead of waiting for a whole page.
  - Pulling to load older messages is earlier and smoother: the next page is prefetched, so new content is usually ready by the time you reach the top.
  - Connections set up more quickly: waiting on a connection conflict drops from 1.5s to about 0.8s, relaxing automatically on weak networks.
  - Downstream compression: the same content travels faster and uses less data on cellular.
- Fixes:
  - Fixed session details freezing — scrolling and gestures unresponsive — in large sessions with live output.
