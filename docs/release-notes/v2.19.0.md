# v2.19.0

## 中文

- 新增：
  - 代码块支持一键复制：会话里每个代码块都有复制按钮，长消息里的代码块同样可以复制，复制内容就是代码原文。
  - 会话详情底部新增「子代理 + 后台任务」共用入口，点开后可切换查看子代理列表与后台任务；运行中的后台任务可以直接停止。
- 改进：
  - 推送通知标题改为会话名称，正文直接说明需要你做什么：回合结束、等待作答 n 个问题、等待审批：工具名、回合失败。
  - 置顶会话集中到「工作区」标题下方的独立区域，卡片更紧凑，取消置顶自动回到原工作区。
  - 详情页等待作答图标的跳动幅度更明显，更容易注意到。
- 修复：
  - 离线状态的云朵图标不再是错误轮廓，详情页与列表显示一致。

## English

- New:
  - One-tap copy for code blocks: every code block in a session now has a copy button, including code blocks inside long messages; the copied text is the code itself.
  - A shared "subagents + background tasks" entry at the bottom of the session detail. Open it to switch between the subagent list and background tasks, and stop a running background task directly.
- Improvements:
  - Push notifications now use the session name as the title, and the body says what you need to do: turn finished, waiting for answers to n questions, waiting for approval: <tool>, or turn failed.
  - Pinned sessions now sit in their own area right below the Workspaces title with more compact cards; unpinning returns the session to its workspace.
  - The waiting-for-answer icon in the session detail now animates with a more noticeable bounce.
- Fixes:
  - The offline cloud icon now shows the correct outline, consistent between the session detail and the list.
