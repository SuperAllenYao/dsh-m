# v2.15.0

## 中文

- 新增：
  - 会话详情右上角常显状态图标，一眼看清这一刻的会话状态：离线、等待审批、等待作答、进行中、出错、未开始、空闲。进行中的图标持续转动，等待类状态轻轻起伏呼吸。
  - 会话列表卡片状态行换成同一套图标，并拆出「等待审批」「等待作答」两种状态。
  - 列表状态实时刷新：一轮对话开始或结束，卡片立刻变化并自动置顶，不用等下拉刷新。
  - 过程组默认平铺展开：思考和工具调用一行一条排开，组头显示「N 步 · 运行中 / 已完成」，点一下即可收起整组。
  - 实时思考：模型思考时，思考内容在组内逐字增长；超过三行自动淡出，点开可以看全文。
  - 工具准备行：工具还没真正开始时先显示「准备运行命令…」，开始后转为运行中，返回后显示成功或失败。
- 改进：
  - 收起或展开过程组时，组头停在原位不动，只有下方内容展开或收回，不再跳动或反向。
  - 置顶标记与会话标题垂直居中对齐，看起来更整齐。
  - 会话卡片左滑的置顶、归档按钮改为纯图标，更紧凑。
- 修复：
  - 新建的草稿会话现在固定排在列表顶部，创建后立刻可见（与 DSH 桌面端一致）；此前它会被排到列表较下方，需要下滑才能找到。
  - 断线重连后，偶发的卡片一直显示「进行中」且占着置顶位（下拉刷新也恢复不了）不再出现：连接恢复后卡片状态以最新数据为准。
  - 一轮对话结束后，已经手动收起的过程组不再被自动弹开。

## English

- New:
  - Every session detail shows a persistent status icon in the top-right corner, so the session's state is clear at a glance: offline, waiting for approval, waiting for an answer, running, error, not started, idle. The running icon keeps turning; waiting states breathe gently.
  - Session list cards now use the same icon set on their status line, with separate "waiting for approval" and "waiting for an answer" states.
  - List status updates live: when a turn starts or ends, the card changes immediately and moves to the top, with no pull-to-refresh needed.
  - Process groups are expanded by default: thinking and tool calls line up one per row, and the group header shows "N steps · running / done"; tap it to collapse the whole group.
  - Live thinking: while the model is thinking, the thinking text grows word by word inside the group; after three lines it fades out, and tapping opens the full text.
  - Tool preparation row: a tool that has not really started yet shows "Preparing to run command…", turns into running once it starts, and shows success or failure when it returns.
- Improvements:
  - Collapsing or expanding a process group keeps the group header exactly in place: only the content below opens or closes, with no jump and no reversed motion.
  - The pin mark is vertically centered with the session title for a tidier look.
  - The pin and archive buttons revealed by a left swipe are now icon-only, which is more compact.
- Fixes:
  - A newly created draft session now stays at the top of the list and is visible immediately (matching the DSH desktop app); it used to land further down and require scrolling to find.
  - A card that occasionally stayed stuck on "running" (and pinned to the top, unfixable by pull-to-refresh) after a reconnect no longer happens: once the connection recovers, card status follows the latest data.
  - Process groups you collapsed manually are no longer reopened automatically when a turn ends.
