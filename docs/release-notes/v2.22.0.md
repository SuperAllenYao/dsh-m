# v2.22.0

## 中文

- 修复：
  - 会话详情与子代理会话详情在实时思考输出时滚动卡顿、滚动条反复闪烁、消息内容高频闪烁的问题已修复；现在无论是否在实时输出，上下滑动都跟手流畅，实时思考内容照常显示。

- 改进：
  - 滚动条恢复为 iOS 系统原生的一条，不再出现两条滚动条互相闪烁。
  - 滚动过程中，尾部正在生成的思考与回复文字会暂停增长以保持滑动顺畅，手指停下后 1 秒内自动补齐，内容不丢。
  - 向上翻看更早的消息时继续按需加载，不会出现滑到顶部没有更多内容的情况。

## English

- Fixes:
  - Fixed stuttering, scrollbar flicker and message flicker in session and subagent session details while reasoning text streams; scrolling is now smooth whether or not content is streaming, and live reasoning still shows.

- Improvements:
  - The scrollbar is back to the single native iOS one, so two indicators no longer flicker over each other.
  - While you scroll, the tail of streaming reasoning/reply text pauses growing so scrolling stays smooth; it catches up within a second after you stop, with nothing lost.
  - Scrolling up keeps loading older messages on demand, so you never hit a dead end at the top.
