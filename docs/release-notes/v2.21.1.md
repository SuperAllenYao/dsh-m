# v2.21.1

## 中文

- 新增：
  - Mac 端插件改为 DSH 标准插件安装：在 DSH 的插件管理器里添加安装包即可完成安装，卸载与升级由 DSH 统一管理，重启桌面端不会再丢失。
  - 安装包内置手机连接所需的部署组件，部署页不再提示缺少文件。

- 改进：
  - 安装包随附完整安装说明，覆盖全新安装、从旧版迁移、升级、回滚与常见故障；安装步骤不依赖任何机器的具体路径，换一台 Mac 也能照着装。

- 修复：
  - 升级到新版 DSH 后插件无法启动、配对页提示版本不兼容、手机连不上 Mac 的问题。
  - 插件不可用时状态显示更明确，不再出现「看似正常但连不上」。

## English

- New:
  - The Mac plugin now installs as a standard DSH plugin: add the package from the DSH plugin manager, and DSH takes care of uninstalling and upgrading. A desktop restart no longer loses the plugin.
  - The package bundles the components the phone connection needs, so the deploy page no longer reports missing files.

- Improvements:
  - The package ships complete installation notes covering fresh install, migration from the previous setup, upgrade, rollback and common failures. The steps do not depend on any machine-specific path, so another Mac can follow the same guide.

- Fixes:
  - After upgrading DSH, the plugin could fail to start, the pairing page reported an incompatible version, and the phone could not connect.
  - When the plugin is unavailable, the status now says so clearly instead of looking fine while connections fail.
