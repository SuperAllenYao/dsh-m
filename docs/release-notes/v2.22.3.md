# v2.22.3

## 中文

- 修复：
  - 手机和 Mac 不在同一个 Wi-Fi 时，连接不再先去试探一个已经失效的本地地址；只有确认真实处在同一网络才直连，其余情况直接走服务器中转，Wi-Fi 下连不上、反复重连的问题解决。
  - 从锁屏通知点进会话详情，历史消息现在会稳定自动补齐，不再偶尔停在空白或进度条不启动。
- 改进：
  - 在 Wi-Fi 与 5G 之间切换后恢复在线更快，通常约 1 秒内完成。

## English

- Fixes:
  - When the phone and the Mac are not on the same Wi-Fi, the app no longer tries a local address that is no longer reachable; it connects directly only when both are confirmed on the same network, and uses the relay otherwise — resolving the Wi-Fi "cannot connect" and repeated reconnect loops.
  - Opening a session from a lock-screen notification now reliably fills in the full history instead of occasionally staying empty or never starting the progress bar.
- Improvements:
  - Coming back online after switching between Wi-Fi and 5G is faster, typically within about a second.
