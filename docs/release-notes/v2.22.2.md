# v2.22.2

## 中文

- 修复：
  - 取消置顶后卡片回到分组位置时，左滑的「置顶 / 归档」按钮不再抢先闪出来；现在按钮只在左滑时出现，点完卡片收回即隐藏。
  - 展开或收起工作区里的会话列表时，左滑按钮不再在列表出现前闪一下。

## English

- Fixes:
  - After unpinning a session, the swipe actions (Pin / Archive) no longer flash into view before the card returns to its group. They appear only when you swipe, and hide again as the card settles back.
  - Expanding or collapsing a workspace's session list no longer makes the swipe actions blink before the list appears.
