# v0.2.5

## 中文

- 改进：
  - 连接大幅提速：跨网络冷启动从约 2.5 秒降到 0.7 秒左右，App 一打开几乎就在线。
  - 工作区列表 1 秒内就绪；刷新够快时不再闪「本地缓存」提示，从会话返回列表也不再出现。
  - 切换网络后约 0.7 秒自动恢复连接。
- 修复：
  - 修复冷启动「连接中」要停 2–3 秒的问题。
  - 修复桌面端重启后首次打开、列表长时间停在「正在刷新」的问题。

## English

- Improvements:
  - Much faster connections: cross-network cold start drops from ~2.5 s to ~0.7 s — you're online almost the moment the app opens.
  - The workspace list is ready within a second; quick refreshes no longer flash a "local cache" notice, and neither does returning from a session.
  - After a network switch the connection recovers in about 0.7 s.
- Fixes:
  - Fixed "connecting" lingering 2–3 seconds on cold start.
  - Fixed the list staying on "refreshing" for a long time after a desktop restart.
