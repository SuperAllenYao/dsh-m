# v2.17.0

## 中文

- 改进：
  - 网络切换后几乎即时恢复：在 Wi-Fi 与蜂窝之间来回切换，连接约 1 秒内自动恢复，不用再等好几秒（双向真机实测均在 1 秒内）。
  - 切换网络后不再出现反复「正在重连」或长时间无响应的情况。

## English

- Improvements:
  - Nearly instant recovery after a network switch: toggling between Wi-Fi and cellular restores the connection automatically in about a second, instead of waiting several seconds (measured under 1s in both directions on a real device).
  - No more repeated "reconnecting" states or long unresponsive stretches after switching networks.
