# v2.22.5

## 中文

- 修复：
  - 子代理会话不再产生任何通知：运行中的子代理任务结束、等待审批或提问时，不会再打扰通知中心与锁屏。
  - 从锁屏通知直接进入会话详情，状态条会自动显示该会话原本选好的模型，不需要先打开一次模型列表。
  - 更正 v2.22.4 说明中的误实现：子代理会话不会被通知打开；v2.22.4 的静默推送与本地网络声明修复继续有效。

## English

- Fixes:
  - Subagent sessions no longer produce any notifications: a running subagent that finishes, waits for approval or asks a question no longer interrupts the notification center or the lock screen.
  - Opening a session from a lock-screen notification now shows that session's chosen model right away — no need to open the model list first.
  - Corrects a wrong claim in the v2.22.4 notes: subagent sessions are not opened from notifications; the silent-push and local-network fixes from v2.22.4 remain in effect.
