# v2.8.0

## 新增
- **会话实时镜像**：用户消息、思考、工具调用/结果、过程组步数、流式文本、文件变更卡等所有尾部变化**恒应用**到消息列表；读历史（非贴底）只保护阅读锚点，不再冻结尾部。两端逐事件核对：sim 94/94、真机 27/27 事件 0 缺失，端到端延迟 avg 21–42ms / max 259ms（LAN/relay 实测）。
- **文件变更详情弹层可自由拖拽调高**：按住顶部触摸条连续调整高度（下限 240pt/32% 屏、上限 92% 屏），下滑超阈值收起；打开 diff 时自动先撑高到可读档位；其余底部弹层行为不变。
- **GitHub 风格行内 unified diff**：文件列表内点行原地展开（不再推二级页），旧/新双行号、`+`/`-` 符号列、`@@` hunk 头、行级红绿背景、横向滚动、2000 行截断、多文件同时展开、失败行内重试；配色采用 GitHub Primer dark（#0d1117 / #161b22 / rgba(46,160,67,.15) / rgba(248,81,73,.1) / #3fb950 / #f85149）。
- **精确摘要磁盘缓存**：按 `sessionId+seq` 缓存成功取到的 Host 精确摘要（上限 200 条），Host 重启/释放后仍优先显示上次精确数字。

## 改进
- **文件变更卡只在主会话空闲（turn/end 后）出现**；running 期间完全不渲染，也不发起取数请求。
- **卡片永不显示「读取中/转圈」**：精确摘要未到时先显示工具聚合数字，exact 到达后同一行原地替换；来源标签为「Host / 工具聚合」。标题文件数使用 Host `total`，与桌面端口径一致。
- **贴底跟随改为自证 + 有限重试**：以「底部哨兵行进入视口」为唯一判据（未到底按 20/50/100/200/400ms 退避重试）；冷启动历史补齐（autoload）期间保留系统底部锚点直到首次真实滚动，不再漂移到旧内容。
- **HistoryFiller 自愈**：失败/中断/推送重开流后冷却 10s 自动重启；空页按 1/2/4s 退避重试，避免永久停在 `hasMoreOlder=true`。

## 修复
- 修复会话详情**上滑无法加载历史**（补齐任务被取消/失败后无人重启）。
- 修复 App 停在会话窗口时**新消息/思考步骤不实时出现**（`isNearBottom` 误判导致尾部结构性更新被永久冻结）。
- 修复冷启动历史补齐期间**视口漂移到旧内容**。
- 修复文件变更卡**一直显示在会话底部**、**一直转圈/「读取中」卡死**。
- 修复文件变更详情弹层**高度过低**、推入二级页后内容被压缩。
- 修复 diff 使用 App 自有配色而非 GitHub 标准配色。
- 修复 Host 摘要 404 后文件变更卡整卡消失/数字口径不一致。
