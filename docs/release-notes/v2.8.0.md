# v2.8.0

## 中文

- 新增：
  - 会话实时镜像：桌面端每产生一条消息、一个思考或工具步骤，手机上都实时出现；正在读历史时新内容安静等待，不打断阅读。
  - 文件变更详情可自由拖拽调整高度，点开时自动展开到可读高度。
  - GitHub 风格行内对比：新增/删除行红绿高亮、双行号、横向滚动、多文件同时展开。
- 改进：
  - 文件变更卡只在回合结束后出现，且从不转圈：先显示概要数字，精确数字到达后原地更新。
  - 历史加载失败会自动恢复重试，不再永久停在「还有更早内容」。
- 修复：
  - 修复上滑无法加载历史的问题。
  - 修复停在会话里看不到新消息实时出现的问题。
  - 修复冷启动补历史期间画面漂移到旧内容的问题。
  - 修复文件变更卡一直停在会话底部、一直转圈的问题。
  - 修复对比配色不标准的问题（改为 GitHub 深色配色）。

## English

- New:
  - Live session mirroring: every message, reasoning or tool step that appears on the desktop shows up on the phone in real time; while you read history, new content waits quietly instead of interrupting.
  - File-change details can be dragged to any height, and auto-expand to a readable one when opened.
  - GitHub-style inline diffs: red/green added and deleted lines, dual line numbers, horizontal scrolling, multiple files open at once.
- Improvements:
  - The file-change card appears only after the turn ends and never spins: a summary number shows first and updates in place when the exact one arrives.
  - History loading now recovers and retries on its own instead of stalling forever at "more content available".
- Fixes:
  - Fixed being unable to load history by swiping up.
  - Fixed new messages not appearing live while you stayed in the session.
  - Fixed the view drifting to old content while history filled on a cold start.
  - Fixed the file-change card lingering at the bottom and spinning forever.
  - Fixed non-standard diff colors (now the GitHub dark palette).
