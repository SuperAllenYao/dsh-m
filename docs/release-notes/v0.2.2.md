# v0.2.2

## 中文

- 新增：
  - 桌面端切换模型后，手机会话页实时跟随显示新模型，无需重新进入。
- 改进：
  - 连接更快：并行探测地址，同一 Wi-Fi 冷启动约 1.6 秒连上，切换网络后约 0.4 秒恢复。
  - App 图标补齐全部尺寸，通知栏与设置中显示正确图标。
- 修复：
  - 修复桌面端切换模型后手机断连、持续报错的问题。
  - 修复提示「帧解析失败」后该会话再也无法打开的问题。
  - 修复推送通知不显示 App 图标的问题。

## English

- New:
  - Model switches made on the desktop now appear on the phone's session page instantly, no re-entry needed.
- Improvements:
  - Faster connections: addresses are probed in parallel — about 1.6 s cold start on the same Wi-Fi, about 0.4 s to recover after a network switch.
  - The app icon now ships every size, so notifications and Settings show the right one.
- Fixes:
  - Fixed the phone losing connection and erroring after a desktop model switch.
  - Fixed sessions becoming unopenable after a "frame parse failed" message.
  - Fixed push notifications not showing the app icon.
