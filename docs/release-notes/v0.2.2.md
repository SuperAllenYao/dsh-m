# v0.2.2

## 新增
- 桌面端切换会话模型后，手机 App 的会话页状态行实时同步显示新模型，无需重新进入会话。

## 改进
- 协议容错：会话事件出现新的字段形态时不再整帧丢弃；确实无法解析时会明确提示帧类型与具体字段（例如 `帧解析失败: [snapshot] 缺少字段 header`），便于快速定位。
- App 图标补齐全部 iPhone 尺寸（含 3x），通知栏、设置等系统界面显示正确的 DSH-m 图标。

## 修复
- 修复桌面端切换模型后手机连接中断、App 持续报错的问题。
- 修复会话页显示「帧解析失败」后该会话无法打开的问题。
- 修复推送通知左侧不显示 DSH-m App 图标、只显示灰色占位的问题。
