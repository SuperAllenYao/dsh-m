# v2.25.0

## 中文

- 新增：在手机上直接查看文件内容。点会话里的文件名（工具行文件名、变更列表里的路径、正文里的文件链接）即可在底部面板打开文件：带行号、只读，长文件自动分页加载，看到末尾会显示总行数；长行可以左右滑动看到行尾。
- 新增：图片在手机上全屏预览。点图片直接全屏查看原图，双指捏合或双击放大、缩小后自动回弹，左右滑动切换同一组里的其它图片，右上角显示当前是第几张。
- 改进：子代理列表与后台任务列表按创建时间倒序排列，新创建的任务始终在最上面。
- 修复：手机端消息里的图片有时显示「图片加载失败」、加载不出来的问题；现在图片能正常显示，在蜂窝网络下同样可用。

## English

- New: Read file contents right on your phone. Tap a file name — in a tool row, in the list of changed files, or a file link in a message — and it opens in a bottom sheet with line numbers, read-only, paged loading for long files, and a total line count at the end. Long lines scroll horizontally to the end.
- New: Full-screen image preview. Tap an image to view the original at full screen, pinch or double-tap to zoom with spring-back when you shrink below fit, swipe left and right to move through other images in the same message, and the top-right corner shows which one you are on.
- Improvements: Subagent and background-task lists are now sorted newest first, so a task you just started stays on top.
- Fixes: Images in messages could show "image failed to load" on the phone. Images now load reliably, including over cellular.
