# v2.24.0

## 中文

- 改进：桌面端升级到 0.2.2 后，手机端查看历史会话、翻页改用桌面端的新接口，加载更稳定；桌面端如果退回旧版本，插件会自动切回旧接口，手机端不需要重新配对、也不需要升级。
- 修复：会话详情页里的 Markdown 表格恢复按列对齐显示，单元格不再被挤成一行文字；表格比屏幕宽时，可以在表格内部左右滑动查看。

## English

- Improvements: After the desktop updates to 0.2.2, viewing history and paging on your phone use the new desktop interface and load more reliably. If the desktop is rolled back, the plugin switches back to the older interface automatically — no re-pairing and no app update needed.
- Fixes: Markdown tables in the session view are laid out in aligned columns again, and cells no longer collapse into a single run of text. Wide tables can be scrolled horizontally inside the table.
