# v0.2.7

## 新增
- **过程组四态内联**：运行中默认「高度受限窗口」（上限整屏 1/3、clamp 280–360pt；步数少时按内容自适应，不留空白），底部对齐展示最新步骤；点组头右侧箭头（窗口/折叠态 ▶、全高/展开态 ▼，与 DSH 桌面端 TurnProcess 箭头一致，100ms 旋转）→ 全量内联，再点回窗口；本轮结束自动折叠成一行「N 步 · …」（组头不再出现「过程」二字），点该行 → 展开全部历史步骤，再点 → 收起。
- **展开/收起交互**：被点击的组头在屏幕上**严格固定不动**——内容向下展开、自下而上收起，150ms ease-in-out 非线性动画；不使用任何自动滚动/上移。
- **失败步骤回到步骤序列**：失败/待审批步骤按事件原始顺序内联在过程组内（不再单拎成独立卡片；折叠态不单独显示），与 DSH 桌面端展示顺序一致。
- **跨端文件变更一致性**：卡片标题文件数改用 Host `total`（不再是客户端 `files.length`）；精确摘要未到时卡片/sheet 显示 loading 态，不拿近似值冒充；打开 sheet 时重新取数。

## 改进
- **R0 手势还给外层列表**：运行中窗口去掉嵌套 `ScrollView`，只渲染窗口容量内的最近 N 步（底部对齐），纵向 pan 不再被窗口吞掉 → 整页消息列表恢复上下滑动；看全部用「全高」。
- **消息列表原生 SwiftUI 重写（最终方案）**：消息流从 UIKit 反转 UITableView 改为原生 `ScrollView + LazyVStack`，展开/收起完全由 SwiftUI 布局动画驱动，展开内容不再被旧行高裁剪、也不再有自撑高行高与隐式动画错配；长会话整页滚动门禁耗时从 ~205s 降到 26.6s。
- **运行中窗口高度自适应**：窗口高度 = min(整屏 1/3, 整行吸附的内容高度)，步骤少时不再出现大片空白。
- **通用折叠/展开锚点交互**：任何可展开行（过程组、思考块、中继卡、用户问题卡）点击后，**被点行在屏幕上位置严格不动**，展开内容把下方 UI 向下挤开、收起反向拉回，统一 150ms ease-in-out。
- **R2 读历史冻结**：读历史（不在贴底区）时尾部新内容暂不插入（保持阅读位置），过程组模式/turn 相位等交互变更仍然立即生效；回到贴底时一次性补齐最新内容。
- **R3 运行中组判定**：新增「本轮起点 seq」（`isNewest = 最后一个组 && firstSeq > currentTurnStartSeq`），刚发消息时上一轮组不再闪成运行中窗口。

## 修复
- 修复运行中固定窗口吞纵向手势导致**整页消息列表无法上下滑动**。
- 修复读历史时点「过程 · N 步」**无反应**（交互被冻结门吞掉、后续 diff 丢失）。
- 修复单独思考块点开后**看不到全文**（cell 内展开行高不失效 / 内容被裁剪）。
- 修复思考块**点开后收起时行高不回收**、上下上下文内容不归位（原先只对「变高」触发重测）。
- 修复运行中窗口在步骤较少时**上方大片空白**（窗口高度按内容自适应，上限 1/3 屏）。
- 修复运行中组角标语义与桌面端相反：改为折叠/窗口态 ▶、全高/展开态 ▼。
- 修复过程组组头多余文案「过程 · 」，改为直接显示「N 步 · …」。
- 修复折叠/展开**整屏弹跳 / 内容闪动**（过程组、思考块、子代理卡、问题详情）：消息列表由 UIKit 反转 UITableView 重写为**原生 SwiftUI ScrollView + LazyVStack**，展开/收起交回 SwiftUI 布局动画（150ms ease-in-out + 裁剪），彻底移除此前「self-sizing 行高 + 隐式动画」错配导致的跳变；贴底跟随、读历史冻结尾部、历史补齐保持阅读位置、强制回底等行为在新列表中保持一致。
- 修复会话详情页**滚动后被自动吸回固定位置**（冷启动也会）：逐帧锚点只对「用户主动点击的展开体」生效，首屏渲染/流式内容/历史补齐的行高变化改回无锚点重测。
- 修复一轮结束收到**多条「DSH 回合完成」通知**：插件侧按 APNs push token 去重、配对成功及启动时清理历史重复设备记录，并给 turn-end/failure 加 `apns-collapse-id`（同一事件重复投递由 iOS 折叠成一条）。
- 修复刚发消息时上一轮过程组闪成运行中窗口。
- 修复文件变更卡片在 Host 已释放摘要（404）时**整卡消失**：链路插件把已经解压的 error body 配上 `content-encoding: gzip` 透传，客户端把 404 误判成可重试的传输错误并耗尽重试；现改为解压失败回退原始 body，正确进入 404 终态并走近似兜底。
- 文件变更兜底聚合兼容 `message.meta`（部分恢复快照只保留该位置；真实会话仍以 `data.meta` 为准）。
- 文件变更 fallback 列表行补齐可测性标识（E2E 可计数/定位）。
