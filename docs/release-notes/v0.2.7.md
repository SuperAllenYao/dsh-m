# v0.2.7

## 中文

- 新增：
  - 工作步骤内联到消息流：运行中显示一个高度受限的实时窗口（最多约占屏幕三分之一），点开看全部、再点收起；本轮结束自动折叠成一行摘要。
  - 任何可展开的内容（过程组、思考块、子代理卡等）点开后，被点的那一行在屏幕上原地不动，内容向两侧展开或收起。
- 改进：
  - 运行中的窗口不再挡住整页滑动；步骤少时不再有大片空白。
  - 文件变更数量与桌面端口径完全一致；数字未到齐时如实显示加载中，不用近似值冒充。
- 修复：
  - 修复运行中窗口吞掉手势、导致整页消息列表滑不动的问题。
  - 修复翻历史时点过程组无反应、思考块点开看不到全文或收起不归位的问题。
  - 修复展开/收起时整屏弹跳、内容闪动的问题。
  - 修复一轮结束收到多条重复「回合完成」通知的问题。
  - 修复刚发消息时上一轮过程组误闪成运行中的问题。
  - 修复文件变更卡片在数据不可用时整卡消失的问题。

## English

- New:
  - Work steps are now inline in the message flow: while running, a capped live window (at most a third of the screen) shows the latest step — tap to see everything, tap again to collapse; when the turn ends it folds into a one-line summary.
  - Anything expandable (process groups, thinking blocks, subagent cards…) stays exactly where you tapped it while its content expands or collapses.
- Improvements:
  - The running window no longer blocks scrolling the whole list, and no longer leaves large blanks when there are few steps.
  - File-change counts now match the desktop exactly, with honest loading states instead of approximations passed off as exact.
- Fixes:
  - Fixed the running window swallowing gestures so the whole list couldn't scroll.
  - Fixed taps on process groups doing nothing while reading history, and thinking blocks showing no full text or not restoring when collapsed.
  - Fixed whole-screen jumps and flicker on expand/collapse.
  - Fixed receiving multiple duplicate "turn finished" notifications.
  - Fixed the previous turn's group flashing as running right after you send a message.
  - Fixed file-change cards vanishing entirely when their data was unavailable.
