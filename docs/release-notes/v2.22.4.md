# v2.22.4

## 中文

- 修复：
  - 从锁屏通知直接进入会话详情，状态条会立刻显示该会话原本选好的模型，不需要先打开一次模型列表。
  - 子代理会话的通知会直接打开对应的子代理详情，不再被当成普通会话打开。
  - 后台静默推送恢复：App 在后台或锁屏时，系统会允许它被静默推送唤醒，列表与待处理状态能更及时刷新（iOS 仍按系统预算尽力而为，不保证实时）。
  - 同 Wi-Fi 下发现 Mac 的系统声明补齐，本地直连判断不再缺这一环。

## English

- Fixes:
  - Opening a session from a lock-screen notification now shows that session's chosen model in the status strip right away — no need to open the model list first.
  - Notifications for subagent sessions now open the subagent's own detail instead of being opened as a normal session.
  - Background silent push is restored: while the app is in the background or the screen is locked, the system allows it to be woken for silent pushes, so the list and pending state refresh sooner (iOS still schedules these on a system budget; not guaranteed to be real-time).
  - The local-network service declaration the system requires is now in place, so same-Wi-Fi Mac discovery no longer misses that piece of the direct-connection check.
