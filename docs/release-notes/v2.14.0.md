# v2.14.0

## 中文

- 修复：
  - 进入会话详情后，历史加载不再卡住页面：顶部进度条走动期间也能自由上下滑动、随时点返回或侧滑返回，不用等加载结束。
  - 长会话打开后更跟手：加载期间的后台解析不再抢占界面响应。
- 改进：
  - 进详情页的加载过程更顺滑，页面从第一秒起就能操作。

## English

- Fixes:
  - Opening a session no longer freezes the page while its history loads: you can scroll freely and go back (button or edge swipe) while the progress bar is still moving, without waiting for it to finish.
  - Long sessions feel more responsive right after opening — background parsing no longer competes with the interface while loading.
- Improvements:
  - The load transition into a session is smoother, and the page is usable from the first second.
