# v2.12.0

## 中文

- 新增：
  - 会话卡片左滑即可置顶或归档；归档带二次确认弹窗，误触不会丢会话
  - 分组标题上的「+」一键新建会话并直接进入；输入到一半的内容自动存为草稿，回到该工作区可继续
- 改进：
  - 顶栏品牌与版本信息重排：版本号移到第二行，两行高度与 logo 对齐，顶部更整齐
  - 新建的空白会话与有消息的会话布局完全一致
- 修复：
  - 新建空白会话时内容挤成中间窄条、上下出现黑边的问题

## English

- New:
  - Swipe a session card left to pin or archive it; archiving asks for confirmation first, so a stray swipe never loses a session
  - The「+」on a group header creates a new session and jumps straight into it; half-typed input is kept as a draft until you come back
- Improvements:
  - Header redesign: the version number moves to a second line level with the logo, so the top bar looks tidier
  - A brand-new empty session now lays out exactly like one that already has messages
- Fixes:
  - New empty sessions no longer collapse into a narrow strip with black bands above and below
