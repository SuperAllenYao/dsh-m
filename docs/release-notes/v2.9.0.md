# v2.9.0 — 2026-10-24

## 新增 / New

- **会话详情本地缓存最近 300 条消息**：二次进入直接渲染缓存窗口并贴底（缓存 schema v6；升级后每个会话首次打开是一次冷启动）。/ Session detail now caches the newest 300 messages per session: reopening renders the cached window instantly and lands at the bottom (cache schema v6; the first open after upgrading is a one-time cold start per session).
- **会话详情显示窗口**：默认只渲染最近 300 行并跟随新内容，后台补齐的更早历史不再插入当前内容；向更早历史滚动时每次平滑扩展 100 行。/ A display window in session detail: only the newest 300 rows are rendered and follow new content; background history no longer inserts into the visible list; scrolling into older history expands the window by 100 rows at a time.
- **会话详情顶部 2pt 历史补齐进度条**（不遮挡内容）。/ A 2pt top progress bar while older history is still being filled.
- **工作区列表 UI 收尾**：内联版本/统计、两行工作区名、chevron 旋转、自绘形变文件夹图标。/ Workspace list UI polish: inline version/stats, two-line workspace names, rotating chevron, custom morphing folder icon.

## 改进 / Improvements

- **会话详情滚动管理重写**：删除 `defaultScrollAnchor` 与贴底自证重试链，改为「可视锚点 + contentOffset 精确补偿」；内容高度变化通过 UIScrollView `contentSize` 的 KVO 在同一布局事务内精确补偿。/ Session-detail scroll management rewritten: removed `defaultScrollAnchor` and the bottom-retry chain, replaced by a visible-anchor + exact contentOffset compensation model; content-size changes are compensated synchronously inside the same layout transaction via KVO on UIScrollView `contentSize`.
- **贴底状态只在手势结束后改写**，静置期间没有任何定时滚动；首屏定位完成前内容不可见（不出现“先顶部再跳到底”）。/ Bottom-follow state is only updated when a gesture ends; no timers scroll the list while idle; content stays hidden until the initial bottom position is ready (no "top first, then jump").
- **DEBUG 真机 HUD 与 E2E 探针扩展**（kvo/pan/wstart/pref 等），真机与模拟器 E2E 可直接取证。/ Extended DEBUG on-device HUD and E2E probe fields for direct evidence capture.

## 修复 / Fixes

- 进入会话后**第一次滑动整屏跳变**（后台补历史与手势并发插入内容）。/ Fixed the full-screen jump on the first swipe after opening a session (concurrent background history insertion).
- 静置/切前后台时列表**自行滚动**、末行被裁或底部出现空档。/ Fixed the list "scrolling by itself" while idle or after foregrounding, clipped last rows and bottom gaps.
- 返回重进后距底 5000+pt 的**错位**。/ Fixed the 5000+ pt mis-position after leaving and re-entering a session.
- 开发期滚动补偿逻辑的无限递归崩溃（未进入发布）。/ Fixed an infinite-recursion crash in the development scroll-compensation code (never shipped).

## 已知限制 / Known limitations

- 单会话缓存上限 4MB，tool-heavy 会话实际缓存可能少于 300 条（从最老 chunk 裁剪）。/ Per-session cache is capped at 4 MB; tool-heavy sessions may cache fewer than 300 messages (oldest chunks dropped first).
- 跨会话缓存沿用既有清理策略，未新增全局 LRU 上限。/ Cross-session cache keeps the existing pruning policy; no additional global LRU cap.
- 会话内「向上翻历史」靠窗口扩展续接，极端快速长距离滑动时会在窗口边界处有一次 100 行的插入补偿（已保证 0 像素可见位移）。/ Scrolling far into history relies on window expansion; at the window boundary an extra 100-row insertion is compensated (0 visible pixel shift is preserved).
