# v2.9.0

## 新增
- **会话详情本地缓存最近 300 条消息**：二次进入直接渲染缓存窗口并贴底（缓存 schema v6；升级后每个会话首次打开是一次冷启动）。
- **会话详情显示窗口**：默认只渲染最近 300 行并跟随新内容，后台补齐的更早历史不再插入当前内容；向更早历史滚动时每次平滑扩展 100 行。
- **会话详情顶部 2pt 历史补齐进度条**（不遮挡内容）。
- **工作区列表 UI 收尾**：内联版本/统计、两行工作区名、chevron 旋转、自绘形变文件夹图标。

## 改进
- **会话详情滚动管理重写**：删除 `defaultScrollAnchor` 与贴底自证重试链，改为「可视锚点 + contentOffset 精确补偿」；内容高度变化通过 UIScrollView `contentSize` 的 KVO 在同一布局事务内精确补偿。
- **贴底状态只在手势结束后改写**，静置期间没有任何定时滚动；首屏定位完成前内容不可见（不出现“先顶部再跳到底”）。
- **DEBUG 真机 HUD 与 E2E 探针扩展**（kvo/pan/wstart/pref 等），真机与模拟器 E2E 可直接取证。

## 修复
- 进入会话后**第一次滑动整屏跳变**（后台补历史与手势并发插入内容）。
- 静置/切前后台时列表**自行滚动**、末行被裁或底部出现空档。
- 返回重进后距底 5000+pt 的**错位**。
- 开发期滚动补偿逻辑的无限递归崩溃（未进入发布）。
