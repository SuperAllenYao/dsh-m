# v2.24.1

## 中文

- 修复：当电脑上的桌面端版本较旧时，手机通过备用通道打开会话历史会失败；现在插件会自动改用旧接口，手机端无需重新配对，也不需要升级 App，看历史不再偶发失败。

## English

- Fixes: Opening session history over the backup channel could fail when the desktop app was on an older version. The plugin now falls back to the earlier interface automatically — no re-pairing and no app update needed, and history opens reliably again.
