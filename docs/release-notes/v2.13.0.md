# v2.13.0

## 中文

- 修复：
  - 手机在任何网络下都能扫码配对：同一 Wi-Fi 下自动走最快的局域网直连，直连不通或处在移动网络时自动走中继，不再出现「扫了没反应」。
  - 配对一次即可长期使用：Wi-Fi 与移动网络之间来回切换会自动重连换路，不需要重新扫码或重新配对。
  - 修复输入 8 位配对码时提示「服务器配置与服务器不匹配」的问题。
  - 桌面端配对二维码不再过期失效，点一下即可放大，更容易扫上。
- 改进：
  - 配对更快：同一 Wi-Fi 下约 1–2 秒完成，跨网络约 3–5 秒完成；失败时给出一句可操作的提示，并可直接重新扫码。

## English

- Fixes:
  - Pair by scanning the QR code on any network: on the same Wi-Fi the app takes the fastest local connection automatically, and falls back to the relay when the direct path is unavailable or you are on cellular — no more "scanned but nothing happened".
  - Pair once and stay paired: switching between Wi-Fi and cellular reconnects and re-routes automatically, with no need to scan or pair again.
  - Fixed the "server configuration does not match the server" message when entering the 8-digit pairing code.
  - The desktop pairing QR code no longer goes stale, and can be tapped to enlarge for easier scanning.
- Improvements:
  - Faster pairing: about 1–2 seconds on the same Wi-Fi and about 3–5 seconds across networks; failures now show one actionable line and you can simply scan again.
