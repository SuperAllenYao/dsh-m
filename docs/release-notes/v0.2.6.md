# v0.2.6

## 中文

- 新增：
  - 打开会话自动补齐全部历史，直到最早一条：无需任何操作，补齐过程中可正常滚动阅读。
  - 翻看历史时新消息安静等待，回到底部后一次性出现；发出消息立即跳到底部，刚发的内容马上可见。
- 改进：
  - 滚动明显更顺：补历史与缓存写盘的重活挪到后台，快速滑动不再卡顿。
  - 首次打开会话不再是约 2 秒空白：框架先上屏，内容约 0.6 秒内跟上。
- 修复：
  - 修复后台补历史时内容整屏跳变的问题（补齐全程画面纹丝不动）。
  - 修复翻历史时发消息看不到自己刚发内容的问题。
  - 修复键盘弹出时正在读的内容整体跳动的问题。

## English

- New:
  - Opening a session now backfills all history down to the very first message — no buttons, no spinners, and you can keep scrolling while it fills.
  - While reading history, new messages wait quietly and appear together when you return to the bottom; sending a message jumps you straight to it.
- Improvements:
  - Noticeably smoother scrolling: the heavy work moved to the background, so fast swipes no longer stutter.
  - No more ~2-second blank on first open: the frame appears immediately and content follows within about 0.6 s.
- Fixes:
  - Fixed the whole screen jumping while history filled in (it now stays perfectly still).
  - Fixed not seeing your own just-sent message while reading history.
  - Fixed reading content jumping around when the keyboard appeared.
