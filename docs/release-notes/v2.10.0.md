# v2.10.0

## 中文

- 新增：
  - **会话详情自绘滚动条**：消息列表右缘的滚动指示条（对标系统指示条外观），滑块贴底 = 看最新、贴顶 = 翻到最旧，滚动时浮现、停稳后淡出，两端橡皮筋时压短。
- 改进：
  - **消息列表 inverted 化重构**：数据倒序渲染 + 双轴翻转（scaleEffect），最新消息天然贴底（offset=0），历史补齐在布局远端追加——**数学上零像素漂移**。删除全部滚动补偿链（贴底跟随、锚点回位、首屏追底、settle 收敛，净删约 300 行），滚动指令只剩用户手势与回底动作。
  - **读历史期间新消息静默等待**（与 iMessage 行为一致）：翻历史时新消息不会把正在阅读的内容推走，回到底部后恢复跟随。
  - **E2E 取证矩阵扩充**：旋转挂法取证（rotationEffect/scaleEffect 对照）、跳动采样、滚动条可见性/位置断言；过期测试资产清理（下拉加载入口相关 4 个用例随功能删除）。
- 修复：
  - 无缓存进入长会话时历史补齐期间的**画面跳动/漂移**（补偿链在 LazyVStack 高度估值抖动期反复滚动的根因整体移除）。
  - 自绘滚动条首版贴左缘、数据冻结两处缺陷。

## English

- New:
  - Self-drawn scroll indicator on the right edge of the session message list: thumb at the bottom means newest, at the top means oldest; fades in while scrolling, fades out after settling, compresses at rubber-band edges.
- Improvements:
  - Message list rebuilt as an inverted list (reversed rendering + double-axis flip): the newest message sits at the visual bottom for free (offset=0), history fills append at the far end of the layout — zero-pixel drift by construction. All scroll-compensation chains were deleted (~300 lines removed); the only scroll commands left are user gestures and back-to-bottom.
  - While reading history, incoming messages wait silently (matching iMessage): they never push the content you are reading; following resumes when you return to the bottom.
  - Expanded E2E forensics: rotation/scale mount-point matrix, jitter sampling, indicator visibility/position assertions; removed 4 stale pull-to-load test cases whose feature no longer exists.
- Fixes:
  - Fixed visible jitter/drift while older history fills in after entering a session with no cache (the whole compensation chain — and its jitter during LazyVStack height re-estimation — is gone).
  - Fixed the first-drawn indicator sitting on the left edge and its data snapshot freezing.
