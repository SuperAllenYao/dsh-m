# v2.10.0 — 2026-10-25

## 新增 / New

- **会话详情自绘滚动条**：消息列表右缘的滚动指示条（对标系统指示条外观），滑块贴底 = 看最新、贴顶 = 翻到最旧，滚动时浮现、停稳后淡出，两端橡皮筋时压短。/ Self-drawn scroll indicator on the right edge of the session message list: thumb at the bottom means newest, at the top means oldest; fades in while scrolling, fades out after settling, compresses at rubber-band edges.

## 改进 / Improvements

- **消息列表 inverted 化重构**：数据倒序渲染 + 双轴翻转（scaleEffect），最新消息天然贴底（offset=0），历史补齐在布局远端追加——**数学上零像素漂移**。删除全部滚动补偿链（贴底跟随、锚点回位、首屏追底、settle 收敛，净删约 300 行），滚动指令只剩用户手势与回底动作。/ Message list rebuilt as an inverted list (reversed rendering + double-axis flip): the newest message sits at the visual bottom for free (offset=0), history fills append at the far end of the layout — zero-pixel drift by construction. All scroll-compensation chains were deleted (~300 lines removed); the only scroll commands left are user gestures and back-to-bottom.
- **读历史期间新消息静默等待**（与 iMessage 行为一致）：翻历史时新消息不会把正在阅读的内容推走，回到底部后恢复跟随。/ While reading history, incoming messages wait silently (matching iMessage): they never push the content you are reading; following resumes when you return to the bottom.
- **E2E 取证矩阵扩充**：旋转挂法取证（rotationEffect/scaleEffect 对照）、跳动采样、滚动条可见性/位置断言；过期测试资产清理（下拉加载入口相关 4 个用例随功能删除）。/ Expanded E2E forensics: rotation/scale mount-point matrix, jitter sampling, indicator visibility/position assertions; removed 4 stale pull-to-load test cases whose feature no longer exists.

## 修复 / Fixes

- 无缓存进入长会话时历史补齐期间的**画面跳动/漂移**（补偿链在 LazyVStack 高度估值抖动期反复滚动的根因整体移除）。/ Fixed visible jitter/drift while older history fills in after entering a session with no cache (the whole compensation chain — and its jitter during LazyVStack height re-estimation — is gone).
- 自绘滚动条首版贴左缘、数据冻结两处缺陷。/ Fixed the first-drawn indicator sitting on the left edge and its data snapshot freezing.

## 已知限制 / Known limitations

- 列表滚动条为自绘（SwiftUI 翻转布局下系统指示条不可用），粗细/淡出节奏为固定值。/ The scroll indicator is self-drawn (the system indicator is unusable under the flipped layout); width and fade timing are fixed values.
- 会话内翻历史靠窗口扩展续接（每次 100 行，零位移）；跨网络 E2E 依赖真机在线。/ Deep history relies on window expansion (100 rows per step, zero shift); cross-network E2E requires the real device to be online.

## 验证 / Verification

- 单元测试：**913 / 0 failures**（基线 905 + 冻结/滚动条几何 9 例新增）。/ Unit tests: 913, 0 failures (905 baseline + 9 new freeze/indicator-geometry cases).
- 真机（iPhone 16 Pro Max / iOS 26）跳动采样：历史补齐全程 **offset=0.0 恒定、reversals=0、maxStep=0.0**，displayed 10→151 持续补齐，全程零程序滚动指令。/ Real-device jitter sampling: offset stays at 0.0 for the whole fill (reversals=0, maxStep=0.0), displayed grows 10→151, zero programmatic scroll commands.
- 插件套件：apns-payload-shape 11/11、m2-reload-handoff 3/3、m2-transport 8/8。/ Plugin suites: apns-payload-shape 11/11, m2-reload-handoff 3/3, m2-transport 8/8.
